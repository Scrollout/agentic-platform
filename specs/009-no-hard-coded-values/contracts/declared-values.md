# Contract draft: declared values, configuration and the three checks

Draft for the [plan](../plan.md). The authoritative copies live with their providers: the check
contract (`src/check/api/preview/2026-11-13-preview/openapi.yaml`, runCheck description), the
catalogue README (`src/catalogue/api-feature-go/README.md`), the template and the Go doc comments
of `engine/checks`. Research R1, R2, R4 and R7 give the reasons.

## Go interface (package `engine/checks`)

```go
// Declared is one value the contract states under a schema keyword.
type Declared struct {
    Pointer string // RFC 6901 JSON Pointer of the keyword's value, e.g. /components/schemas/NewNote/properties/text/maxLength
    Keyword string // maxLength ... const, or enum (for an item of an enum)
    Kind    string // "number", "string", "bool", "null"; or "unjudged" for a number no Go constant reads
    Text    string // the scalar's text as written in the contract
    Value   constant.Value // the number or string; nil for bool, null and unjudged
    Name    string // the Go constant in gen/declared.go; "" for enum items, bool, null and unjudged
}

// DeclaredValues finds every declared value of contract (the YAML text), in document order, and
// names them, avoiding the names in taken (the top-level names of the other files in gen/).
// An error means the text is not one YAML document without duplicate keys.
func DeclaredValues(contract []byte, taken map[string]bool) ([]Declared, error)

// RenderDeclared is gen/declared.go for values: the same bytes for the same values.
func RenderDeclared(values []Declared) []byte

// DeclaredValuesGenerated: the project's gen/declared.go equals RenderDeclared of the approved
// contract's values (taken from the project's other gen/ files).
func DeclaredValuesGenerated(project string, approvedContract []byte) []CheckResult

// DeclaredValuesNotRepeated judges the step's own non-test .go files (matched by writable)
// against the approved contract's values.
func DeclaredValuesNotRepeated(project string, writable []string, approvedContract []byte) []CheckResult

// DeploymentValuesConfigured judges the step's own non-test .go files (matched by writable).
func DeploymentValuesConfigured(project string, writable []string) []CheckResult
```

`approvedContract` is the YAML text: the check service takes it from the request's `approved`
entry for `contract`, whose content is the canonical JSON `{"contract": "<text>"}`, and passes the
text. Every result has `Part: "project"` and the check's name, as every step check.

## What the contract declares (`DeclaredValues`)

Input: the YAML text, parsed as the fit conditions parse it (one document, no duplicate key).

- A **declared value** is the scalar under a mapping key `maxLength`, `minLength`, `maximum`,
  `minimum`, `exclusiveMaximum`, `exclusiveMinimum`, `maxItems`, `minItems`, `maxProperties`,
  `minProperties`, `multipleOf`, `default` or `const`; an **enum value** is a scalar item of a
  sequence under a key `enum`. A key whose value is not a scalar declares nothing.
- The walk is depth first in document order, mapping keys in their written order. A key
  `example`, `examples` or `x-*` hides its whole subtree (a property so named included: a limit).
  Aliases and merge keys (`<<`) are not followed: a value under an anchor is found once, at the
  anchor.
- Kind, by the node's resolved tag: `!!str` is a string; `!!bool` is `bool`, `!!null` is `null`.
  An `!!int` or `!!float` is a number when its text, after removing a leading `+` and putting `0`
  before a leading `.` (or `-.`), matches `^-?(0|[1-9][0-9]*)(\.[0-9]*)?([eE][-+]?[0-9]+)?$`; its
  value is `constant.MakeFromLiteral` of that normalised text (as a float when it holds `.`, `e` or
  `E`). Any other number text (`.inf`, `.nan`, `010`, `0x1F`, `0o17`, `1_000`) is `unjudged`. A
  quoted `"200"` is a string.
- The pointer encodes `~` as `~0` and `/` as `~1`; sequence items are their 0-based index.

## `gen/declared.go` (written by the generate procedure, `RenderDeclared`)

- Line 1 `// Code generated by the generate procedure from api/openapi.yaml. DO NOT EDIT.`, a blank
  line, `package gen`.
- Then, for each value with a `Name`, in document order: a blank line, `// <Name> is declared at
  <pointer written with %q>.`, and `const <Name> = <value>`, a string written with
  `strconv.Quote`, a number as its normalised text (so `0.5` stays `0.5` and `2e2` stays `2e2`;
  never `ExactString()`, which writes `1/10`).
- `<Name>` is `Declared` followed by each pointer segment, after dropping the segments
  `components`, `schemas`, `properties`, `paths`, `content` and `schema`, decoded (`~1`, `~0`),
  with every character outside `[A-Za-z0-9]` removed and the character after each removed run and
  the first of each segment upper-cased: `/components/schemas/NewNote/properties/text/maxLength`
  is `DeclaredNewNoteTextMaxLength`. A name already given, or in `taken`, gets `_2`, `_3`, ... (the
  first free one).
- Names follow the contract: a change to the contract can rename a constant.
- With no named value the file is the header and `package gen` only.

## `gen/config.go` (in the pattern's template)

```go
// The service's configuration: every value it reads from its environment when it starts.
//
//   LISTEN_ADDRESS  the address the service listens on; default ":8080"
package gen

// ListenAddress is LISTEN_ADDRESS, or ":8080" when it is unset or empty.
func ListenAddress() string
```

## Check `DeclaredValuesGenerated` (generate step)

Passes when `gen/declared.go` is byte for byte `RenderDeclared` of the approved contract's values:
`gen/declared.go equals the <n> declared values of the approved contract`. Fails naming a missing
file, a differing file, or an approved contract that does not parse.

## Check `DeclaredValuesNotRepeated` (code step)

Judged files: every `.go` file the step's `writable` matches, except `_test.go` files. Each
integer, floating-point and string literal (rune and imaginary aside) is compared with the values
of kind `number` and `string`: numbers by `constant.Compare` (a literal whose parent is a unary
`-` is negated; a parenthesised one is not), strings after `strconv.Unquote`, byte for byte; a
string never equals a number. Never judged: `0`, `1`, `-1`, `""`, import paths, struct tags.

- Fails, once per literal: `<file>:<line> repeats <value %q, cut to 64 characters>, declared at
  <pointer>[, <pointer>...]: use gen.<Name>` (an enum value: `use the enum constant oapi-codegen
  generated for it in gen/api.gen.go, where it exists`), ending `; if the literal does not stand
  for this value, write it another way`.
- Passes: `examined <n> files and <m> literals against <k> declared values: none repeated`.
- Fails closed: an approved contract that is missing or does not parse, a judged file that does
  not parse; such a result names what could not be read.
- Limits: a value computed from several literals, a parenthesised negative, a declared boolean or
  unjudged number, and the four exempt values are not judged; a literal equal to a declared value
  that does not stand for it is rejected.

## Check `DeploymentValuesConfigured` (code step)

Same judged files. Fails, once per offence, `<file>:<line> holds <kind>: belongs in configuration:
read it through gen/config.go`. The reason never quotes the literal (a URL can carry a password
in its userinfo):

| Kind | Found when |
|------|------------|
| an address | a string literal that is a URL with a scheme and host; an IP address; or `host:port` / `:port` whose port is a decimal 1 to 65535 and whose host is empty, `localhost`, an IP address or a name holding a letter |
| a credential | a non-empty literal argument of `SetBasicAuth`; the second argument of `Set`/`Add` whose first argument is the literal `Authorization`, `Proxy-Authorization`, `Cookie` or `X-Api-Key` (any case); a literal assigned, declared or keyed to a name matching `(?i)passw(or)?d\|secret\|token\|api_?key\|credential\|private_?key` |
| an environment read | a call of `os.Getenv`, `os.LookupEnv`, `os.Environ` or `os.ExpandEnv`, through any import name of `os` |

A literal argument may be literals joined by `+`. Passes: `examined <n> files: no address,
credential or environment read`. Fails closed on a judged file that does not parse. Limits: a port
written as a number, `":0"`, a credential under another name or call, and values built at run time
are not recognised; `"1.2.3.4"` and `const tokenHeader = "X-Api-Key"` are judged as an address and
a credential.
