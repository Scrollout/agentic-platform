# Contract draft: declared values, configuration and the two checks

Draft for the [plan](../plan.md). The authoritative copies live with their providers: the check
contract (`src/check/api/preview/2026-11-13-preview/openapi.yaml`, runCheck description), the
catalogue README (`src/catalogue/api-feature-go/README.md`) and the template.

## What the contract declares (one collector, `checks.DeclaredValues`)

Input: the approved contract's text, parsed as for the fit conditions (one YAML document, no
duplicate key; otherwise the check fails and generation is refused).

A **declared value** is the scalar value of a mapping key `maxLength`, `minLength`, `maximum`,
`minimum`, `exclusiveMaximum`, `exclusiveMinimum`, `maxItems`, `minItems`, `maxProperties`,
`minProperties`, `multipleOf`, `default` or `const`, at any depth of the document, except below a
key `example`, `examples` or `x-*`. An **enum value** is a scalar item of a sequence under a key
`enum`, with the same exceptions. A key whose value is not a scalar (a property named `default`,
say) declares nothing. Each value carries its location as a JSON Pointer (RFC 6901), for example
`/components/schemas/NewNote/properties/text/maxLength`. Booleans and nulls are recorded but never
judged (no Go literal can repeat them).

## `gen/declared.go` (written by the generate procedure)

- Package `gen`, header `// Code generated by the generate procedure from api/openapi.yaml. DO NOT EDIT.`
- One untyped constant per declared value that is a number or a string, in pointer order:
  `const <Name> = <value>` with the doc comment `// <Name> is declared at <pointer>.`
- `<Name>` is `Declared` followed by each pointer segment after dropping `components`, `schemas`,
  `properties`, `paths`, `content` and `schema`, with `~1` and `~0` decoded, every run of
  characters outside `[A-Za-z0-9]` removed and the next character upper-cased, and the first
  letter of each segment upper-cased: `/components/schemas/NewNote/properties/text/maxLength` is
  `DeclaredNewNoteTextMaxLength`. When two pointers give one name, the later in pointer order gets
  `_2`, `_3`, ... A name that does not start with a letter after `Declared` is valid as is.
- No values: the file holds the header and `package gen` only.
- Two generations from one contract give the same bytes (the procedure's existing two-run rule).

## `gen/config.go` (in the pattern's template)

```go
// The service's configuration: every value it reads from its environment when it starts.
//
//   LISTEN_ADDRESS  the address the service listens on; default ":8080"
package gen

// ListenAddress is LISTEN_ADDRESS, or ":8080" when it is unset or empty.
func ListenAddress() string
```

## Check `DeclaredValuesNotRepeated` (code step)

Judged files: every `.go` file the step's `writable` matches, except `_test.go` files. Each
integer, floating-point and string literal is compared with the declared and enum values:
numbers by exact value (`go/constant`; a literal directly under unary `-` is negated), strings
after unquoting, byte for byte. Never judged: `0`, `1`, `-1`, `""`, import paths, struct tags.

- Fails, once per literal: `<file>:<line> repeats <value>, declared at <pointer>[, <pointer>...];
  use gen.<Name>` (an enum value: `use the enum constant oapi-codegen generated for it`).
- Passes: `examined <n> files and <m> literals against <k> declared values: none repeated`.
- Fails closed: the approved contract missing or not parsing, a judged file that does not parse.
- Limits: a value computed from several literals, a declared boolean, and the four exempt values
  are not judged.

## Check `DeploymentValuesConfigured` (code step)

Same judged files. Fails, once per offence, naming `<file>:<line>` and the kind:

| Kind | Found when |
|------|------------|
| address | a string literal that is a URL with a scheme and host, an IP address, or `host:port` / `:port` with port 1-65535 and host empty, `localhost`, an IP or a name with a letter |
| credential | a non-empty literal argument of `SetBasicAuth`; the value of `Set`/`Add` whose first argument is the literal `Authorization`, `Proxy-Authorization`, `Cookie` or `X-Api-Key` (any case); a literal assigned, declared or keyed to a name matching `(?i)passw(or)?d\|secret\|token\|api_?key\|credential\|private_?key` |
| environment | a call of `os.Getenv`, `os.LookupEnv`, `os.Environ` or `os.ExpandEnv`, by any import name of `os` |

A literal argument may be literals joined by `+`. The reason ends `belongs in configuration: read
it through gen/config.go`. Passes: `examined <n> files: no address, credential or environment
read`. Fails closed on a file that does not parse. Limits: a port written as an integer, a
credential under another name or call, and values built at run time are not recognised.
