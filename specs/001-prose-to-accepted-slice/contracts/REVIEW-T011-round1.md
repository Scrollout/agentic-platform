# Contract review T011, round 1 (Opus, 2026-11-12): REJECT, 18 blocking findings

Fix every blocking finding. "OA" = engine-api.openapi.yaml.

- B1 Principle V/XIV/XX, FR-024: one token scheme lets every token call everything. Define `clientToken` (all developer operations), `pageToken` (GET only), `workerToken` (only registerWorker); set `security` per operation; add 403 `Forbidden`; add `x-operation-name` (`Agentic.Engine/<type>/<read|write|delete|action>`) per operation so the operations list derives from the contract.
- B2 FR-015, 14-day expiry: hand-over is both terminal and waiting. Add `Run.status` (`running`, `interrupted`, `waiting-for-developer`, `ended`), `outcome` only when ended (`done`, `handed-over`, `expired`, `cancelled`), `expires_at`; define that a run waiting for the developer ends as handed-over when the developer accepts the hand-over or expired after 14 days, and which operation resumes from `interrupted` (resumeRun), with 409 codes.
- B3 ADR 0004, Values have one home: error codes are prose only. Make `Problem.code` an enum and list codes per response (`x-error-codes`), incl. NarrowDescription, TooManyQuestions, ContradictionOpen, PartFailsChecks, ProjectExists, InvalidProject, NotApproved, PatternDoesNotFit, WorkersNotReady, RunActive, StaleContentHash, IdempotencyKeyReused, RateLimited, Forbidden, MissingApiVersionParameter, UnsupportedApiVersionValue, NotFound, BudgetExhausted.

- B7 FR-003, SC-006: examples have no ids. Each scenario carries `@R-<n>` and `@E-<n>` tags; E-n stable; state the ExampleTagged check.
- B8 FR-005, SC-002: slice `checks` items must require `part`, `check`, `passed`, `reason`; `part` has an id pattern; additionalProperties false.
- B9 FR-017, D11, FR-018, SC-006: run-event fields must be required by kind (if/then): Check* requires `check` and `refs` (minItems 1); FindingRecorded requires `finding`, and blocking requires file, line and a confirming check; AttemptMade/StepAccepted require model, agent_digest, pattern, inputs, artifacts, reuse_key.
- B10 FR-018, Principle III/XX: analyst proposals lack provenance. Add `slice.history[]` entries {kind: proposed|revised|answered|changed|approved, at, model?, agent_digest?, refs[]}.
- B11 US2.9, FR-024: no way to read an artifact. Add `GET /runs/{runId}/artifacts/{hash}` (getArtifact) returning content with media type (pageToken and clientToken).

- B14 Values have one home, FR-006: answer request body oneOf {option: integer 0-4} | {text: string maxLength 200}; shared 429 response with `Retry-After` header and the 20 requests/second/token limit stated.
- B15 Principle XVII: proposal schema copies the slice schema. Make the proposal `$ref` shared `$defs` (put goal, term, rule, question in a shared defs file or in slice.schema.json `$defs`) so there is one home.
