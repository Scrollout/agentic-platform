# src/check

The check service's contract (`api/preview/2026-11-13-preview/openapi.yaml`, research D29) and the Go module of its generated code. One program, `src/engine/cmd/check` (package `engine/checksvc`), serves it in two deployments: the check service, which reads the project folder and runs the pattern's step checks (runCheck) and returns an agent step's files (readStepFiles), and a procedure step's worker, which runs that step's fixed procedure and writes its files (runProcedure).

A blocking review finding is confirmed only by the new witness test it carries (research D35, [ADR 0039](../../docs/decisions/0039-review-findings-confirmed-by-a-new-witness-test.md), superseding the rule-test rerun of ADR 0031): FindingsCarryEvidence and NoBlockingFindingOpen run that one test alone, offline, as `go test -json -count=1 -covermode=set -coverpkg=./... -coverprofile=<outside the project> -run '^<test>$' ./review/r<n>/`, and confirm the finding only when it fails having run the finding's line, in a file the fix step may change, and a baseline run with `-run '^$'` (what package initialisation runs) does not cover that line. A finding without a witness, or whose witness is not a new `_test.go` file of the review step in its rule's folder declaring `TestR<n>...`, is a suggestion; a witness that does not build fails both checks. TestsUnchanged also keeps every witness in `before` unchanged, and only the review step adds one. runCheck's description states each rule. A finding's `check` is informational and not consulted. The review step declares `findings` (not a set of files) and the file-set output `witnesses` under `review/**`.

Known limits (research D29, D35): only a path's last part is protected against a symbolic-link race; a child process that calls `setsid` escapes the process group a time limit kills, and the deployment's container (constitution VIII) contains it; and in `set` coverage mode a line counts as run once its block is entered, so a witness that stops inside the line's block still confirms it.

Generated server interfaces, client and types: `api/gen/check.gen.go`, made by `scripts/generate.sh` from `api/check.oapi-codegen.yaml` (Go names from `api/check.overlay.yaml`, which also keeps `finding.witness.test` in the Go type, since oapi-codegen merges the contract's `allOf` by property); never edited or committed. The engine's `machine.Checker` will use the client (T054c).

The contract is linted with the project ruleset (`scripts/check.sh`, `s_contracts`) and its limits live once, in its root `x-limits`; the service reads them from its embedded copy.
