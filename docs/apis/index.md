# API

* [Check API](check-api.md) - The check service's HTTP API, called only by the engine, which judges one attempt of a build step with a named check, reads step files, runs fixed procedures, and keeps a project's version history.
* [Engine API](engine-api.md) - The engine's public HTTP API, which the terminal client and the run page call to turn a description into an approved slice, build it, and follow the work.

* [API documentation conventions](conventions.md) - How interfaces the platform exposes or consumes are documented in apis/.
