# agentic-platform

Project knowledge lives in [`docs/`](docs/index.md) as an
[Open Knowledge Format v0.2](docs/references/okf-spec.md) bundle.

```
python3 scripts/okf.py index   # regenerate index.md files
python3 scripts/okf.py check   # validate the bundle
```
